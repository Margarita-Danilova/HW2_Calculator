# HW2:Calculator

Скрипт калькулятора для вычисления простых арифметических выражений из двух чисел и оператора (`+`, `-`, `*`, `/`).
Принимает на ввод строку из двух чисел и математичского оператора между ними. Разделитель междк всеми элемнтами пробел.
Выводит результат математичской операции.
